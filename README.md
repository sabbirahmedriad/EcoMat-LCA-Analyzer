# EcoMat-LCA: Sustainable Textile & Materials Lifecycle Analyzer

An analytical tool designed to evaluate mechanical properties against environmental lifecycle metrics for bio-based and synthetic polymer fibers.

## 🔬 Research Background
Selecting sustainable materials in textile and polymer science requires balancing **mechanical performance** (e.g., tensile strength) with **environmental degradation** (water depletion, carbon footprint, and end-of-life persistence). This tool automates trade-off analysis for eco-friendly fiber selection.

## 🛠️ Key Features
- **Multi-Criteria Optimization:** Calculates a normalized *Polymer Sustainability Index (PSI)*.
- **Environmental Accounting:** Tracks global warming potential ($CO_2$ emissions) and water consumption.
- **Automated Visualization:** Generates publication-ready material property trade-off charts.
